# 可视化工具说明

这是一个完全在本机运行的 TCGA 多模态脑 MRI 查看工具。它会自动扫描相邻的 `TCGA` 数据目录，通过下拉框选择病例，并按需加载 NIfTI 影像。影像和标签不会上传到外部服务器。

## 快速启动

双击 `start-viewer.cmd`。工具启动后会打开：

```text
http://127.0.0.1:4173
```

保持命令窗口打开。使用结束后，在该窗口按 `Ctrl+C` 停止服务。

也可以在此目录打开终端并运行：

```text
npm start
```

首次在新电脑上使用时，需要先安装 Node.js 20 或更高版本。若 `node_modules` 不存在，一键启动脚本会自动运行 `npm install`。

## 预期目录结构

```text
TCGA/
├─ TCGA/                       数据目录
│  ├─ BraTS-TCGA.xlsx
│  ├─ TCGA-02-0003/
│  │  ├─ TCGA-02-0003_T1WI.nii.gz

│  │  └─ TCGA-02-0003_ADC.nii.gz

```

如果完整项目被移动到其他磁盘，只要 `TCGA` 和 `mri-viewer` 仍保持上述相邻关系，就不需要修改路径。

## 使用方法

1. 在顶部“病例”下拉框选择 TCGA 病例。
2. 在“模态”下拉框选择 T1WI、T1CE、T2WI、FLAIR 或 ADC。
3. 使用三个切片滑块浏览轴位、冠状位和矢状位。
4. 点击任意二维视图可移动同步十字线。
5. 在二维视图上滚动鼠标滚轮可以缩放；按住并拖动可平移。
6. 使用“复位视图”恢复二维视图位置。
7. 调节窗位、窗宽，或点击“自动范围”。
8. 可在灰度、热度和 Viridis 色图之间切换。
9. 在三维视图中拖动旋转，滚轮缩放；使用阈值和透明度控制体绘制效果。
10. 点击“复位 3D”恢复三维视角。

左侧面板显示病例标签、影像尺寸、体素间距、空间匹配状态及异常提示。

## 数据加载和内存

- 启动时只建立 243 个病例的文件索引，不加载全部影像。
- 选择模态后才读取对应的 `.nii.gz` 文件。
- 最近使用的影像使用 LRU 缓存，最多 3 个体积、约 192 MiB。
- 快速切换时会取消已经过时的文件请求。
- 三维视图使用约 `120 × 120 × 78` 的降采样数据；二维切片保持原始分辨率。

## 空间检查

病例详情加载时会检查各模态的：

- 图像尺寸；
- 体素间距；
- NIfTI 空间变换矩阵。

若这些信息不一致，工具会显示警告。当前数据集的 1,188 个影像文件头均可读取，已有模态的空间几何一致。


该命令检查目录索引、标签关联、缓存、异常病例、NIfTI 解码、本地接口和正式前端构建。

## 已知限制

- 当前目录没有肿瘤分割掩膜，因此工具不能显示肿瘤轮廓或分割标签。
- 当前版本没有多模态透明叠加功能，但会预先检查各模态是否具备安全叠加的空间条件。
- 三维体绘制是交互式预览，不代替专业影像工作站。
- 二维视图基于标准化体素轴显示；当前版本没有显示患者方向标记（L/R、A/P、S/I）。
- 本工具用于数据浏览和研究质量检查，不用于临床诊断。
- 浏览器需要支持 WebGL 2。建议使用当前版本的 Edge、Chrome 或 Firefox。
